1. Ficha Técnica y Propuesta de Valor

La impresión física desatendida desde aplicaciones web en la nube se ha enfrentado históricamente a tres grandes obstáculos técnicos impuestos por la arquitectura de los navegadores y los sistemas operativos:

  • Interrupción del Cajero (window.print()): Bloquea el hilo de JavaScript, abre un cuadro modal que obliga a pulsar la tecla Enter y descalibra los anchos de los tickets térmicos.
  • Bloqueo de Contenido Mixto (SSL): Una aplicación web segura servida por https:// no puede realizar llamadas HTTP a direcciones locales como http://localhost o http://192.168.1.x.
  • Carga Operativa de Java (QZ Tray): Exige instalar máquinas virtuales de Java en cada terminal de venta y gestionar certificados SSL autofirmados con fechas de caducidad.
  • Altos Costos de Suscripción (PrintNode): Tarifas mensuales recurrentes en dólares por cada impresora o equipo físico conectado.

Nyxo Universal Printer rompe con este paradigma combinando un paquete nativo de Laravel y un agente liviano de Windows basado en llamadas nativas al Spooler del sistema operativo (winspool.drv) y SumatraPDF:

Factor Operativo Solución Tradicional (Navegador / QZ) Solución Nyxo Universal Printer
Velocidad de Salida 3 a 8 segundos con intervención humana obligatoria 0.2 segundos directo a la bandeja física
Ventana Emergente Obligatoria (Ctrl+P) en cada documento Cero diálogos (100% silencioso y en segundo plano)
Certificados SSL Locales Requeridos en cada puesto para eludir bloqueo HTTPS No requeridos (comunicación saliente por puerto 443)

2. Arquitectura del Sistema y Ciclo de Vida de los Datos

El ecosistema opera mediante una cola atómica con bloqueo pesimista en base de datos y un protocolo de sondeo seguro saliente (Outbound Long-Polling):

┌────────────────────────────────────────────────────────────────────────┐ │ APLICACIÓN WEB LARAVEL (Cloud / VPS) │ │ │ │ NyxoPrinter::to($nodeId) │ │ ->title('MI COMERCIO') │ │ ->table($items) │ │ ->total($monto) │ │ ->cut() │ │ ->send(); │ │ │ │ 1. Convierte a flujo binario ESC/POS o Base64 (PDF / RAW / JSON) │ │ 2. Guarda registro atómico en tabla `print_jobs` en estado 'pending' │ └───────────────────────────────────┬────────────────────────────────────┘ │ Polling HTTPS Saliente (Puerto 443 estándar) │ Header: Authorization: Bearer <token> ▼ ┌────────────────────────────────────────────────────────────────────────┐ │ AGENTE DE ESCRITORIO NYXO (PC Cliente / Punto de Venta) │ │ │ │ - Emite latido cada 5 segundos (GET /api/v1/print/ping) │ │ - Retira trabajos pendientes con bloqueo transaccional (GET /jobs) │ │ - Reporta confirmación física de impresión (POST /status) │ └───────────────────┬───────────────────────────────┬────────────────────┘ │ winspool.drv (RAW) │ SumatraPDF (Silent CLI) ▼ ▼ ┌───────────────────────────────┐ ┌───────────────────────────────┐ │ IMPRESORA TÉRMICA DE TICKETS │ │ IMPRESORA CONVENCIONAL A4 │ │ (ESC/POS 80mm / 58mm) │ │ (Láser / Tinta de Oficina) │ │ • Comandas, Tickets, Facturas│ │ • Facturas A4, Remitos │ │ • Guillotina y apertura RJ11 │ │ • Hojas membretadas, PDF │ └───────────────────────────────┘ └───────────────────────────────┘

Ciclo de Estados de un Trabajo de Impresión (`PrintJob`)

  1. pending: El trabajo se genera y persiste en Laravel. Listo para ser despachado.
  2. processing: El agente local consulta GET /jobs. La base de datos aplica lockForUpdate() e incrementa atómicamente el contador de intentos (attempts).
  3. printed: La impresora física confirma la inyección en el spooler. El agente envía POST /jobs/{id}/status con status: 'printed'.
  4. failed: Si ocurre atasco de papel o desconexión física, el agente reporta status: 'failed' con el detalle de error en error_message.

3. Instalación y Configuración Paso a Paso

3.1 Requisitos del Servidor

  • PHP 8.2 o superior (probado en PHP 8.2, 8.3 y 8.4).
  • Extensiones PHP requeridas: ext-iconv (para transliteración de caracteres a CP850), ext-json, ext-mbstring.
  • Laravel 10.x, 11.x, 12.x o 13.x.

3.2 Instalación vía Composer

composer require nyxo-app/nyxo-printer

3.3 Instalador Automatizado

php artisan nyxo-printer:install

Este comando interactivo realiza las siguientes acciones:

  1. Publica el archivo de configuración config/nyxo-printer.php.
  2. Publica las migraciones en database/migrations/.
  3. Publica las vistas Blade y el componente Livewire en resources/views/vendor/nyxo-printer/.
  4. Verifica y copia el instalador del agente de Windows (Nyxo_Universal_Printer_Setup_Win.exe) a la carpeta pública public/downloads/ para permitir auto-hospedaje inmediato.
  5. Ofrece ejecutar automáticamente php artisan migrate.

Configuración en el Agente de Escritorio Windows

🔒 Estado Inicial Limpio de Fábrica (Seguridad y Privacidad)
Por diseño de seguridad estricto y privacidad multi-inquilino, el agente de escritorio de Nyxo se distribuye 100% limpio y desvinculado por defecto:
  • Sin URLs ni Tokens Precargados: Ni la dirección del servidor (saasUrl) ni las credenciales secretas del puesto (tenantToken) vienen predefinidas. La aplicación inicia vacía esperando la vinculación del operador.
  • Sin Parámetros de Emulador por Defecto: Los campos de destino del emulador C# o impresora de red (emulatorUrl) inician vacíos. En cajas y puntos de venta comerciales con ticketeras físicas conectadas por USB/Red, este campo no se utiliza.
  • Sin Licencias ni Puertas Traseras Precargadas: La terminal inicia sin licencia activa. Todas las licencias (tanto la modalidad gratuita para desarrolladores como los planes comerciales) se emiten exclusivamente a través de Lemon Squeezy (https://printer.nyxo.ar).
🛡️ Primer Inicio en Windows 10/11 (Aviso de SmartScreen)
Al ejecutar el instalador o la versión portable por primera vez, es normal que Microsoft Defender SmartScreen muestre una ventana azul informativa ("Windows protegió su PC"), al tratarse de un ejecutable recién distribuido sin un certificado de firma EV corporativo:

Para continuar: Hacer clic en el enlace "Más información" y presionar el botón "Ejecutar de todas formas".

🔄 Demonio en Segundo Plano y Bandeja del Sistema (System Tray)
El agente opera como un servicio desatendido en segundo plano:
  • Al presionar la "X" de la ventana: El programa no se cierra; se minimiza a la Bandeja del Sistema (System Tray) junto al reloj de Windows para evitar que un cajero cierre la aplicación por error e interrumpa la impresión.
  • Para restaurar la ventana: Hacer doble clic en el ícono de la impresora junto al reloj de Windows, o simplemente volver a ejecutar el archivo .exe (el mecanismo Single Instance Lock detectará la instancia en segundo plano y traerá la ventana al frente de inmediato).
  • Para cerrar definitivamente la aplicación: Hacer clic derecho sobre el ícono de la bandeja del sistema y seleccionar "Salir".

⚙️ Proceso de Vinculación Paso a Paso:

  1. Ejecutar Nyxo_Universal_Printer.exe en la PC del puesto.
  2. Abrir la pestaña 🔑 Conexión.
  3. Vinculación en 1 Clic (Recomendado): Pegar el valor de $nodo->codigo_enlace en el campo "⚡ Código de Enlace Rápido" y hacer clic en Pegar y Guardar. El agente desglosa la URL del servidor y el token al instante.
  4. Método Manual: Introducir la URL del endpoint (ej. https://mi-sistema.com/api/v1/print) y el $nodo->print_token.
  5. En la pestaña 🖨️ Impresoras, seleccionar la impresora física asignada para cada formato (Ticket 80mm, Ticket 58mm o A4).
  6. En la pestaña 🛡️ Licencia, ingresar la clave oficial emitida por Lemon Squeezy (variante Developer Free de $0 USD o variantes comerciales) y presionar Activar Licencia.

Monitoreo en Tiempo Real (Heartbeat)

El agente envía un ping automático cada 5 segundos a GET /api/v1/print/ping. Laravel actualiza el campo last_ping_at usando updateQuietly() para no disparar eventos pesados de Eloquent.

5. Especificación Completa de la API REST Interna

Todas las rutas son gestionadas por el controlador PrintJobApiController y blindadas por el middleware CheckPrintToken:

Extracción Multicanal del Token en el Middleware

Para evitar fallas habituales causadas por servidores Apache o proxys que eliminan encabezados estándar, el middleware inspecciona en cascada:

  1. Cabeceras X-Tenant-Token, X-Print-Token, Print-Token, Token.
  2. Cabecera estándar Authorization: Bearer <token>.
  3. Parámetros de consulta o cuerpo ?token= o ?print_token=.
  4. Variables de entorno de servidor HTTP_AUTHORIZATION y REDIRECT_HTTP_AUTHORIZATION.
💡 Auto-Decodificación Inteligente de Enlace Rápido
Si un operador pega el Código de Enlace Base64 completo en el campo de Token, el middleware detecta el separador |, lo decodifica y extrae automáticamente el token real sin arrojar un error 401.

NyxoPrinter::to($nodoId)
    ->title('LOGÍSTICA')
    ->custom(function (Printer $printer) {
        $printer->setLineSpacing(30);
        $printer->getPrintConnector()->write("\x1B\x21\x30"); // Inyección cruda

    ->cut()
    ->send();
⚠️ Regla Crítica en PHP 8.x con Mike42/Escpos
Al invocar $printer->close(), el conector vacía su buffer a null. Extraer los datos del conector después arroja un error fatal implode(): Argument #1 must be of type array|string, null given. En Nyxo Universal Printer esta extracción se realiza siempre antes del cierre dentro de ThermalBuilder::toBase64().

7.2 Emulador de Hardware C# (ESSI Thermal Emulator)

El ESSI Thermal Emulator es una herramienta auxiliar de simulación visual autónoma para desarrolladores, diseñada para diseñar plantillas y probar sin gastar rollos de papel térmico.

  • Herramienta Opcional de Pruebas: En cajas de cobro y puntos de venta reales con impresoras físicas USB, el emulador NO se instala ni se utiliza. El agente viene de fábrica con los campos de emulador completamente vacíos.

    2. En el Agente Nyxo, para conectar al emulador durante el desarrollo, ir a la pestaña 🖨️ Impresoras, seleccionar "🌐 Otra IP:Puerto de Red (TCP)..." (o en la pestaña ⚙️ Ajustes) e ingresar 127.0.0.1:9100.
    3. Al enviar trabajos desde Laravel, el emulador dibujará el ticket en pantalla con animación de salida de papel continuo, conmutador de ancho 80mm/58mm y opción de exportación nativa a PDF.

8.3 Creación de Plantillas Propias con `PrintTemplateInterface`

namespace App\PrintTemplates;

use Nyxo\Printer\Contracts\PrintTemplateInterface;
use Nyxo\Printer\Builders\ThermalBuilder;

class ComandaCocinaTemplate implements PrintTemplateInterface
{
    public function __construct(protected array $comanda) {}

    public function build(ThermalBuilder $ticket): void
    {
        $ticket->center('*** COCINA ***', bold: true, doubleHeight: true)
            ->text('MESA #' . $this->comanda['mesa'] . ' | Mozo: ' . $this->comanda['mozo'])
            ->doubleLine('=');

        foreach ($this->comanda['platos'] as $p) {
            $ticket->text($p['cantidad'] . 'x ' . $p['nombre'], bold: true, doubleWidth: true);
            if (!empty($p['observaciones'])) {
                $ticket->text('   * ' . $p['observaciones']);
            }
        }

        $ticket->line('-')->beep(times: 2)->feed(2)->cut();
    }
}

9.3 Paso 3: El Listener en el Componente Anfitrión (La Solución Completa)

Al pulsar "Imprimir", el modal dispara el evento nyxo-print-requested con los datos seleccionados por el usuario. El componente anfitrión debe escuchar este evento para armar el documento y encolarlo:

namespace App\Livewire;

use Livewire\Component;
use Livewire\Attributes\On;
use App\Models\Orden;
use Nyxo\Printer\Facades\NyxoPrinter;
use Nyxo\Printer\Templates\OrderSummaryTemplate;

class AdministrarOrdenes extends Component
{
    /**
     * Escucha la solicitud de impresión disparada desde el modal de Nyxo
     */
    #[On('nyxo-print-requested')]
    public function ejecutarImpresion(array $payload): void
    {
        $documentId = $payload['documentId'];
        $format = $payload['format']; // 'ticket_80mm', 'ticket_58mm', 'a4'
        $printerNodeId = $payload['printerNodeId'];
        $copies = $payload['copies'] ?? 1;

        $orden = Orden::with('detalles')->findOrFail($documentId);

        if ($format === 'ticket_80mm' || $format === 'ticket_58mm') {
            NyxoPrinter::to($printerNodeId)
                ->width($format === 'ticket_58mm' ? 58 : 80)
                ->copies($copies)
                ->template(new OrderSummaryTemplate([
                    'empresa' => config('app.name'),
                    'order_number' => $orden->id,
                    'fecha' => $orden->created_at->format('d/m/Y H:i'),
                    'cliente' => $orden->cliente_nombre,
                    'telefono' => $orden->cliente_telefono,
                    'equipo' => $orden->equipo,
                    'problema' => $orden->falla,
                    'reparaciones' => $orden->detalles->map(fn($d) => [
                        'nombre' => $d->descripcion,
                        'precio' => $d->precio,
                    ])->toArray(),
                    'total' => $orden->total,
                ]))
                ->send();
        } else {
            $pdf = \Barryvdh\DomPDF\Facade\Pdf::loadView('pdf.orden_a4', ['orden' => $orden]);
            NyxoPrinter::to($printerNodeId)
                ->copies($copies)
                ->pdf(base64_encode($pdf->output()), format: 'a4')
                ->send();
        }
    }
}

10. Guía Oficial de Operación, Configuración y Despliegue del Agente de Escritorio

El agente de escritorio Nyxo Universal Printer es el componente nativo que opera localmente en cada estación de cobro o punto de venta bajo Windows 10/11 (64-bit). Se comunica de forma saliente e ininterrumpida con el backend Laravel y despacha los trabajos físicos al hardware sin necesidad de abrir puertos en el router, sin certificados SSL locales y sin máquinas virtuales de Java.

10.1 Modalidades de Distribución: Instalador Windows vs. Versión Portable

Para adaptarse a las políticas de seguridad de cada comercio o infraestructura corporativa, el agente se distribuye en dos compilaciones oficiales:

Característica Instalador Windows (Setup_Win.exe) Versión Portable (Portable.exe)
Nombre de archivo Nyxo_Universal_Printer_Setup_Win.exe Nyxo_Universal_Printer_Portable.exe
Ruta de ejecución %LOCALAPPDATA%\Programs\Nyxo Universal Printer Cualquier carpeta, escritorio o memoria USB
Permisos de Administrador No requeridos (espacio de usuario) No requeridos (cero instalación)
Accesos Directos Creados automáticamente en Escritorio y Menú Inicio Manuales (según la carpeta elegida)

Uso recomendado Terminales fijas de venta, cajas registradoras y producción continua Demostraciones, soporte técnico y PCs corporativas restringidas
💡 Recomendación para la Versión Portable
Si vas a activar la opción "Arrancar con Windows" en la versión Portable, coloca primero el ejecutable en una carpeta fija y definitiva (por ejemplo, C:\NyxoPrinter\Nyxo_Universal_Printer_Portable.exe) para evitar que el acceso directo de arranque se rompa si mueves el archivo más adelante.

10.4 Pestaña 2: Conexión con el Servidor API (connection-view)

Esta sección administra las credenciales seguras de enlace entre el puesto físico y la nube:

  1. Método Recomendado: Código de Enlace Rápido (1 Clic):

    En el panel web de Laravel, al crear o editar un nodo, pulsa "Copiar Código de Enlace". En la aplicación de escritorio, pulsa "Pegar" junto al campo Código de Enlace Rápido. El agente decodifica automáticamente la cadena Base64 (URL_API|TOKEN_TERMINAL) rellenando ambos campos al instante.

  2. Método Manual:
    • URL del Servidor API: Endpoint REST de sondeo (ejemplo: https://mi-sistema.com/api/v1/print o IP local http://192.168.1.100:8000/api/v1/print).
    • Token de Autenticación / Punto de Venta: Clave secreta alfanumérica asignada al nodo. Incluye botón 👁️ para ver u ocultar el secreto.
  3. Diagnóstico en Vivo:

    El botón "🔍 Probar Conexión" realiza un GET /api/v1/print/ping inmediato, mostrando la latencia en milisegundos y la confirmación del servidor. El botón "💾 Guardar Conexión" encripta y persiste las credenciales localmente, activando el bucle de sondeo automático.

10.5 Pestaña 3: Asignación de Impresoras (Dualidad Spooler Windows y Socket TCP RAW 9100)

Nyxo Universal Printer ofrece un modelo de ruteo independiente según el ancho y tipo de papel del documento:

A. Independencia Total de los 2 Anchos Térmicos y Documentos A4

  • Ticket Térmico 80 mm (48 columnas): Ancho estándar de punto de venta (3 pulgadas). Admite tablas completas con columnas alineadas (Cant, Descripción, P.Unit, Total). Ideal para tickets de venta al público y facturas fiscales.
  • Ticket Térmico 58 mm (32 columnas): Formato estrecho (2 pulgadas). Utiliza maquetación vertical optimizada (Cant x Producto con total en línea inferior). Ideal para comandas de cocina rápida, barras o terminales compactas.
  • Documento A4 (Láser / Inyección): Hojas sueltas (210 x 297 mm) despachadas de forma desatendida mediante SumatraPDF integrado, permitiendo imprimir facturas electrónicas completas en PDF vectorial sin diálogos de usuario.

B. Arquitectura Dual: Drivers de Windows vs. Red TCP Socket RAW (Sin Drivers)

  • Canal 1: Impresoras del Spooler de Windows: Menú desplegable con detección automática de impresoras instaladas (Termica, EPSON TM-T20, Bixolon, POS-80, etc.) inyectando bytes binarios en modo RAW vía winspool.drv.
  • Canal 2: Socket TCP RAW por Red (Puerto 9100 - Driverless): ¡Cero instalación de drivers en Windows! Permite ingresar directamente una dirección IP:Puerto (ej: 192.168.1.100:9100 o 127.0.0.1:9100). Abre un socket TCP directo con el hardware y transmite ESC/POS en milisegundos, eliminando bloqueos en el spooler de Windows.

11. Control de Concurrencia, Resiliencia y Eventos de Ciclo de Vida

11.1 Prevención de Duplicados (Race Conditions)

Para evitar que un ticket se imprima dos veces si el cajero hace doble clic o hay microcortes de red, PrintJobApiController::index() utiliza transacciones con bloqueo pesimista:

$jobs = DB::transaction(function () use ($node) {
    $pendingJobs = PrintJob::deliverable($node->id)
        ->lockForUpdate() // Bloqueo exclusivo a nivel de fila
        ->get();

    if ($pendingJobs->isEmpty()) return collect([]);

    PrintJob::whereIn('id', $pendingJobs->pluck('id'))
        ->update(['status' => 'processing', 'attempts' => DB::raw('attempts + 1')]);

    return $pendingJobs;
});

11.2 Rescate Automático de Trabajos Huérfanos

Si una PC sufre un corte de energía mientras imprimía, el trabajo queda en processing. El scope deliverable() reencola automáticamente cualquier trabajo que haya permanecido en processing por más tiempo que config('nyxo-printer.timeout_minutes') (3 minutos por defecto).

12. Guía de Solución de Problemas y Preguntas Frecuentes (FAQ)

🔴 ¿Por qué la impresora térmica imprime texto con `%PDF-1.7`?

Causa: Se envió un PDF compilado a una impresora térmica con content_type = 'escpos_base64'. Las comanderas reciben texto RAW y no tienen procesador vectorial de PDF.
Solución: Utilizar la sintaxis fluida de ThermalBuilder o una plantilla. Si obligatoriamente se debe imprimir un PDF en papel térmico, configurar format: 'ticket_80mm' y content_type: 'pdf_base64'; el agente de Windows invocará SumatraPDF para rasterizarlo al ancho del rollo.

🔴 Error 401 Unauthorized en Servidores Apache / FastCGI

Causa: Apache descarta por defecto la cabecera Authorization: Bearer en entornos sin SSL.
Solución: Agregar en el archivo public/.htaccess de Laravel:

RewriteEngine On
RewriteCond %{HTTP:Authorization} .
RewriteRule .* - [E=HTTP_AUTHORIZATION:%{HTTP:Authorization}]

🔴 Falla al copiar el Código de Enlace en redes LAN (`navigator.clipboard is undefined`)

Causa: Los navegadores modernos bloquean navigator.clipboard en sitios HTTP no seguros.
Solución: Utilizar un elemento DOM oculto de respaldo:

window.copiarAlPortapapeles = async function(texto) {
    if (navigator.clipboard && window.isSecureContext) {
        try { await navigator.clipboard.writeText(texto); return true; } catch (e) {}
    }
    const t = document.createElement('textarea');
    t.value = texto;
    t.style.position = 'fixed'; t.style.left = '-9999px';
    document.body.appendChild(t);
    t.select();
    const ok = document.execCommand('copy');
    document.body.removeChild(t);
    return ok;
};

🔴 Error en Laravel 13 `MissingAttributeException`

Causa: Laravel 13 activa Model::shouldBeStrict(true) por defecto. Acceder a columnas eliminadas en migraciones antiguas arroja excepción inmediata.
Solución: El paquete oficial nyxo-app/nyxo-printer tiene sus modelos estrictamente higienizados declarando únicamente las columnas existentes en el esquema agnóstico.
